# Borrador visual: Grafik en blanco

Propuesta independiente para revisar el aspecto de la tienda con fondo blanco. Incluye portada y página de Chapitas, diseño adaptable, selector de modelo/cantidad, progreso y ahorro por mayor, galería y preguntas frecuentes.

No es un tema instalable de WordPress. No cambia archivos del tema ni del plugin, no envía consultas, no crea pedidos y no procesa pagos. Las acciones del configurador son una simulación local. Los enlaces de Pulseras y de la tienda actual abren la web publicada en otra pestaña.

Abrir `index.html` desde esta carpeta. Los recursos principales se reutilizan de `../../wordpress/grafik-publicidad/assets/images/`. Dos fotografías reales se cargan desde las URL públicas de Grafik; las fuentes de Google son opcionales, con alternativas del sistema.

Los colores, precios y cantidades del prototipo representan el código 1.8.2/1.3.6 al crear el borrador, no una consulta de inventario ni de configuración actual de WooCommerce. Se conserva el logo existente y se adapta el color del subtítulo mediante CSS para el fondo claro.

Si se aprueba el aspecto, el siguiente trabajo es trasladar estos estilos al tema WordPress y comprobar todas las páginas de WooCommerce. No subir este borrador como tema.
