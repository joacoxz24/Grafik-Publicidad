# Tema Grafik Publicidad

Tema clásico de WordPress preparado para WooCommerce y para el plugin
`Grafik Configurador Tyvek`.

## Instalación

1. Comprime la carpeta `grafik-publicidad` como ZIP.
2. En WordPress abre **Apariencia → Temas → Añadir tema → Subir tema**.
3. Instala y activa el tema.
4. Activa también `Grafik Configurador Tyvek`.
5. Revisa **Apariencia → Personalizar → Grafik Publicidad**.

## Edición sin código

- El logo se cambia desde **Apariencia → Personalizar → Identidad del sitio**.
- Los productos se crean y actualizan desde **Productos** en WordPress.
- La página **Productos** se alimenta automáticamente del catálogo de WooCommerce.
- La portada conserva una tarjeta destacada para el configurador Tyvek.

El tema no contiene credenciales, claves de Flow ni datos de clientes.

## Versión 1.2

Carrusel automático de pulseras y chapitas, catálogo con dos familias destacadas
y páginas de personalización Pulseras y Chapitas. Instalar junto con la versión
1.2 del configurador. Las imágenes vienen incluidas y los enlaces se calculan
